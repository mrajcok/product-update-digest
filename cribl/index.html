Why full-text search matters for modern log analytics | Cribl

  • Cribl Search 4.19 (July 2026) now defaults to using a full-text search capability built on an inverted index of the _raw event message.
  • This full-text search allows for significantly faster alphanumeric token searches across log data without requiring users to know specific field locations.
  • Internal testing on a 1 billion row dataset showed 150x to 350x acceleration for “needle in the haystack” searches using the indexed approach, with greater acceleration for rarer search terms.
  • Full-text search complements existing indexed fields, narrowing the search space before applying structured predicates, and currently supports simple string matching via the where operator with the has string operator, but not wildcards or substring matching.

Inside OcientAIQ™: Dataflows in a unified data platform

OcientAIQ Dataflows: Imperative Programming in SQL

OcientAIQ introduces dataflows, enabling imperative programming directly within SQL. This allows for executing loops, variables, conditionals, and exception handling as a single SQL statement, eliminating the need for application round-trips and simplifying complex analytics.

  • Dataflows are anonymous, ad-hoc SQL scripts submitted like queries, differing from traditional stored procedures by not requiring prior creation or residing in a catalog.
  • Two dataflow types exist: "query" dataflows return a result set (using RETURN SELECT), while "void" dataflows perform actions like inserts or deletes without returning data.
  • Dataflows support variables declared with a @ prefix, encompassing all OcientAIQ data types, and offer three expansion modes: @ for values, @@ for identifiers, and @! for raw text.
  • Control flow structures like IF/ELSEIF, WHILE, FOR loops (including iterator-style loops), and exception handling (TRY...EXCEPTION WHEN...THEN) are now available within dataflows, with optional MAX ITERATIONS for loop control.

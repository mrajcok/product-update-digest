OcientAIQ Unified Data Platform Release Notes — 27.1

OcientAIQ Unified Data Platform version 27.1 introduces new data loading options, transactional support, and enhancements to system observability.

  • Added support for extracting Apache® Parquet™ files with the Data Extract Tool.
  • Introduced the CREATE TRANSACTIONAL PIPELINE SQL statement, with an optional START FOREGROUND clause, enabling transactional pipelines with automatic rollback on failure.
  • JDBC Bulk Loading now supports S3-compatible object stores via the bulkLoadMode = s3 connection parameter.
  • Implemented full transaction support within the database and across JDBC and pyocient drivers, including BEGIN TRANSACTION, COMMIT, and ROLLBACK statements.
  • Added the DROP TASK SQL statement for managing distributed tasks.
  • Expanded system catalog tables with historical data views: sys.pipeline_errors_historical, sys.pipeline_events_historical, sys.pipeline_files_historical, and sys.pipeline_metrics_historical.
  • Added transaction_id and transaction_prefix_len columns to sys.queries and sys.completed_queries, and the transaction_id column to sys.pipelines. Added information_schema.pipeline_status_historical, information_schema.pipelines_historical, and information_schema.transactional_pipeline_status views.
  • The array_to_string SQL function now outputs VARCHAR array values without surrounding quotes.

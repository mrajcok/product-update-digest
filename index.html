Cribl Launches StreamAI with Free Inference, Giving Enterprises Control over AI Costs | Cribl

Cribl launched StreamAI, an enterprise AI gateway designed to control AI costs and improve model efficiency.

  • StreamAI includes a model router that automatically directs AI prompts to the most appropriate model based on cost and performance, leveraging insights from Cribl’s SecIT Bench research (showing up to a 20x cost range with only a 17% accuracy difference between models).
  • The platform offers free inference when using automatic data routing to benchmarked AI models, aiming to eliminate unexpected token expenses.
  • StreamAI incorporates built-in budget controls, circuit breakers, and security features (including bidirectional sensitive data redaction) to manage AI spend and protect sensitive data.
  • It records all AI interactions as audit-ready telemetry for governance and visibility, and is designed to work with both proprietary and open-source models.

Introducing Cribl Detect, Delivering a New Way to SIEM | Cribl

Cribl announced Cribl Detect, a new SIEM built on its existing telemetry platform, aiming to provide a complete SIEM solution at up to 50% less cost than competitors.

  • Cribl Detect offers detection, investigation, and response capabilities without vendor lock-in, leveraging Cribl’s open data platform.
  • The SIEM incorporates AI-powered detection and investigation, utilizing intelligence from Cribl’s AI SOC to automate workflows and prioritize threats.
  • Key features include built-in Detection Posture Management (DPM) for identifying coverage gaps and AI-driven triage for faster incident response.

Fusing security telemetry with business data in ANSI SQL

Ocient enables fusing security telemetry with business data using ANSI SQL, rather than replacing existing SIEM tools.

  • The platform supports joining security data (logs, alerts, telemetry) with business or operational data (fraud ledgers, HR context) using standard SQL queries.
  • OcientAIQ is designed to hold telemetry at full resolution, allowing for interactive queries across large datasets without separate warehousing.
  • The solution provides a general-purpose analytics platform that can be deployed on-premises, in a private cloud, or in air-gapped environments to address data sovereignty and security concerns.
  • The platform's pricing is based on fixed capacity, and not per-query, and provides a unified platform for security, fraud, and network operations teams, using a single copy of the data.

Introducing Active Directory Security Posture Management in Cortex XSIAM - Palo Alto Networks Blog

  • Cortex XSIAM now includes Active Directory Security Posture Management (AD-SPM) as part of its Identity Threat Detection and Response module.
  • AD-SPM continuously monitors Active Directory configurations and permissions without requiring additional tools or scheduled scans, utilizing existing Cortex agents on domain controllers.
  • The system tracks findings linked to persistent asset identities within XSIAM’s Unified Asset Inventory, providing a consolidated view of security posture and change tracking.
  • AD-SPM covers major attack surfaces including Kerberos attacks, delegation abuse, certificate template exploitation (ESC attacks), privilege persistence, and domain controller hardening, using continuously updated detection rules and XQL queries.
